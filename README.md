35岁，前端，80万存款，家人在老家，自己在深圳——这几个标签放在一起，焦虑几乎是必然的。但我想先说一句可能你不太爱听的话：**你的问题不是"赚钱太慢"，而是"资产没有结构，生活没有锚点"。**

80万在深圳不算少，但如果它只是躺在银行里，而你又一个人在深圳租房、生活、消耗，那它确实会越看越让人心慌。下面这份规划，我按"先止血、再造血、最后换轨"的逻辑来写，尽量具体到日常。

---

## 一、先认清你真正的风险点

| 风险 | 现状 | 后果 |
|---|---|---|
| 职业天花板 | 35岁纯前端，可替代性上升 | 裁员后议价能力下降 |
| 家庭分离 | 老婆孩子在老家，你在深圳 | 情感消耗+双份生活成本 |
| 资产单薄 | 80万现金，无结构 | 跑不赢通胀，也扛不住意外 |
| 收入单一 | 只有工资 | 一旦断流，全线紧张 |
| 焦虑内耗 | 想得多做得少 | 时间在焦虑中流失 |

**核心判断：你不适合继续"一个人在深圳死磕纯前端"。** 你要么把家人接来深圳一起扛，要么你回老家/新一线，要么你转型到能远程或能落地的方向。三选一，不能拖。

---

## 二、三年总目标（2026-2029）

1. **收入结构**：工资+副业/远程+理财，三条腿走路，副业月入从0到5000+。
2. **资产结构**：80万拆成应急金、保障、稳健理财、学习投资四块。
3. **家庭方案**：最晚2027年解决分居，要么接来，要么回去。
4. **职业转型**：从前端执行者转向"前端+AI应用+全栈/架构"或"前端+行业解决方案"。
5. **身体与心态**：把焦虑转化为可执行的日课，而不是半夜刷手机。

---

## 三、资产怎么摆（立刻做）

80万不要全放活期，也不要乱投。

- **应急金 10万**：货币基金/银行T+0，随时可取。
- **保障 5-8万/年**：重疾+医疗+定期寿险，你是家庭支柱，必须配。
- **稳健 40万**：大额存单/国债/纯债基金，年化3%左右，求稳。
- **进攻 20万**：指数基金定投（沪深300/中证500/纳指），分12-24个月投完。
- **学习投资 2-3万**：课程、证书、设备、副业启动成本。

> 注意：不要碰不懂的高收益项目，不要借钱投资，不要因为焦虑去赌。

---

## 四、职业转型方向（选1-2个深耕）

纯前端的天花板肉眼可见，但你的优势是"离用户近、能快速出东西"。

1. **前端 + AI 应用**：学 LangChain、RAG、Agent 开发，做 AI 工具站、企业内部提效工具。这是目前最容易被小团队买单的方向。
2. **前端 + 全栈/独立开发**：Next.js + Node/Go + 数据库，能独立交付产品。目标不是进大厂，而是能接私活、做 SaaS。
3. **前端 + 行业**：选一个行业（跨境电商、教育、医疗、金融），深耕业务，做解决方案型前端。
4. **远程/海外**：英语+GitHub+个人作品，投海外远程岗，收入可能翻倍，且能回老家。

**日常学习节奏：**
- 工作日：早上6:30-7:30 学新技术/写代码；晚上21:00-22:30 做副业项目或刷题。
- 周末：至少半天做作品，半天陪家人（视频/回家）。
- 每3个月：产出一个可展示的小项目，发GitHub/小红书/即刻。

## 五、日常计划（可执行版）

**工作日：**
- 6:30 起床，运动20分钟（跑步/跳绳/俯卧撑）
- 7:00-8:00 学习/写代码
- 8:30-18:30 上班（午休抽20分钟看行业资讯）
- 19:30-20:30 晚饭+休息
- 20:30-22:00 副业/作品/学习
- 22:00-22:30 和老婆孩子视频
- 23:00 前睡觉，不刷短视频

**周末：**
- 周六上午：副业/作品
- 周六下午：运动+社交/见朋友
- 周日上午：复盘+规划下周
- 周日下午：陪家人（回家或视频+处理家事）

**每月：**
- 复盘收入支出，检查副业进度
- 读1本书（技术/商业/心理）
- 和老婆深聊一次家庭规划

**每季度：**
- 更新简历/作品集
- 评估是否换工作/接单
- 调整资产配置

## 六、家庭方案（不能拖）

- **方案A：接来深圳**。成本高，但一家在一起，你焦虑会少一半。需要算账：房租+孩子上学+生活，每月多支出多少，你的收入能否覆盖。
- **方案B：你回老家/新一线**。降薪但降成本，远程或本地就业，生活质量可能更高。
- **方案C：你先在深圳冲1-2年，攒够钱/转型成功再回去**。但要有明确时间点，不能无限期。

**建议：最晚2027年做决定。** 分居越久，情感和家庭风险越大。

---

## 七、全方位提升清单

- **技术**：AI应用、全栈、架构、性能优化、英语。
- **商业**：学一点产品、运营、销售，知道钱从哪来。
- **身体**：每周3次运动，体检一年一次。
- **心理**：接受焦虑，但不被它驱动；每天写3件完成的事。
- **社交**：认识3-5个同路人，接单/合作/内推都靠人。
- **家庭**：每天视频，每月至少回一次家。
